Что это и зачем

Хороший запрос к нейросети обычно собираешь по кусочкам: что-то из чужого поста, что-то на ходу переписываешь под себя. prompts.chat решает это иначе - это открытая база, куда сообщество годами добавляло готовые формулировки под конкретные задачи: тексты, картинки, код, исследования

Раньше проект назывался Awesome ChatGPT Prompts, сейчас у него новое имя и свой сайт prompts.chat. В ролике, с которого мы начали, звучит цифра «больше 10 000 промптов» - в реальном списке проекта их 2169, я сверила это напрямую по файлу на странице проекта на GitHub, а не поверила ролику на слово

170 667+звёзд на GitHub у проекта

Цифры сверены напрямую на странице проекта 18.09.2026. Библиотека живая и постоянно пополняется, число у тебя на экране может быть больше

Отдельно открывать сайт и копировать текст промпта вручную не обязательно: библиотека подключается прямо к Claude Code, и он сам предлагает подходящий промпт под задачу, которую ты пишешь

Дальше - шаги от подключения до первого готового промпта в разговоре с Claude Code

Шаг 0. Что нужно до старта

Только открытый Claude Code - программа, в которой ты обычно пишешь задачи текстом. Отдельно ничего скачивать не нужно: всё подключение происходит внутри неё самой, командами, которые вставляешь в то же поле, где обычно пишешь свои задачи

Что это даёт: строки из шагов ниже можно вставлять прямо сейчас, ничего заранее не готовя

Добавь prompts.chat в Claude Code

Куда нажать. В поле, где ты обычно пишешь задачи Claude Code, вставь строку - она добавляет prompts.chat в список готовых расширений (их ставят одной командой, без сайтов и загрузок):

/plugin marketplace add f/prompts.chat

Что увидишь. Подтверждение, что адрес f/prompts.chat добавлен в Claude Code

Что это даёт. Claude Code теперь знает, где взять саму библиотеку - на следующем шаге останется её включить

Включи саму библиотеку

Куда нажать. В том же поле следующей строкой вставь:

/plugin install prompts.chat@prompts.chat

Что увидишь. Сообщение, что prompts.chat подключён, а вместе с ним появилась MCP-связка - способ, которым внешний инструмент становится виден Claude Code как один из его собственных

Что это даёт. 2169 промптов теперь доступны прямо из разговора, без отдельной вкладки в браузере и без ручного копирования

Попроси Claude Code найти готовый промпт под задачу

Куда нажать. Напиши команду со своей темой вместо примера:

/prompts.chat:prompts ревью кода

Что увидишь. Список подходящих промптов из библиотеки с коротким описанием, что каждый делает

Что это даёт. Не сочиняешь запрос с нуля - берёшь готовую формулировку, которую уже проверило на своих задачах сообщество из 170 000+ человек, поставивших проекту звезду на GitHub

Пользуйся библиотекой без Claude Code (по желанию)

Куда нажать. Если не хочешь ничего подключать, просто открой в браузере prompts.chat/prompts и найди нужный промпт через поиск на странице

Что увидишь. Тот же список из 2169 промптов с фильтрами по теме: тексты, картинки, код, исследования

Что это даёт. Библиотекой можно пользоваться и без единой команды - как обычным сайтом: текст промпта копируешь и вставляешь в любую нейросеть, не только в Claude

Если что-то не подключилось

Три вещи, которые проверить по порядку:

  1. Строка /plugin marketplace add ничего не находит - проверь, что Claude Code обновлён до последней версии, команда для подключения расширений появилась не в самых старых версиях
  2. Плагин установлен, но команда /prompts.chat:prompts не запускается - начни в Claude Code новый диалог, старый ещё не знает о добавлении
  3. Хочешь не только искать, а ещё и сохранять свои промпты в личный аккаунт - для этого на сайте prompts.chat/settings есть отдельный ключ доступа, но для поиска и использования готовых промптов он вообще не нужен

Инструмент сейчас бесплатный

Код инструмента открыт по лицензии MIT, а сами промпты - в общественном достоянии по лицензии CC0: пользоваться, копировать и переиспользовать можно свободно, без разрешений и оплаты. Платишь только по своей обычной подписке Claude - библиотека работает поверх неё бесплатно

Готовый промпт - это только начало

Я одна, в декрете, без команды разработки строю системы на нейросетях сама. Одна хорошая библиотека промптов экономит время на одной задаче, но собрать из промптов, инструментов и своих готовых цепочек команд рабочую систему под конкретный проект - это уже не одна строка в поле чата

1.5 млн ₽ оборота проектов за год, с нуля и из декрета

prompts.chat закрывает вопрос одного точного промпта на одной задаче. Если строишь целую систему - контент-завод, автоматизацию, продукт на нейросетях - одного инструмента мало, нужна архитектура под твою конкретную задачу
