RuFlo

Один файл настройки - и вместо одного Клода на задачу выходит команда из 60+ агентов

RuFlo - открытый бесплатный инструмент: подключается к Claude Code, сам распределяет задачи между агентами-специалистами и сам решает, какой модели отдать простой шаг, а какой - сложный

Катерина Арта · @katerinarta_ · сентябрь 2026

Что это и зачем

Claude Code хорошо работает один на один: ты пишешь задачу, он её делает. Но на больших задачах - собрать фичу, прогнать тесты, проверить безопасность - один агент делает всё по очереди, и это долго

RuFlo (в прошлом назывался Claude Flow) добавляет Клоду команду: агенты-«королевы» ведут работу, а агенты-специалисты - код, тесты, ревью, безопасность - разбирают задачи между собой и работают параллельно, а не по очереди

Вторая часть механики - маршрутизация по стоимости. Простой шаг инструмент сам отправляет дешёвой модели, сложный - той, что реально нужна. По цифрам из ролика это экономит до 50% токенов (это то, что списывается с твоего лимита в Клоде за каждый запрос) и растягивает тот же лимит до 250%

Дальше - четыре шага от установки до первой задачи, которую агенты решают вместе

Шаг 0. Что нужно до старта

Только открытый Claude Code в папке твоего проекта. Программу Node.js (это то, на чём работают такие инструменты с командами вместо кнопок) отдельно ставить не нужно: она у тебя уже стоит, потому что на ней работает сам Claude Code

Что это даёт: команды ниже можно вставлять прямо сейчас, ничего заранее не готовя

Установи RuFlo мастером настройки

Куда нажать. Рядом с окном, где ты обычно пишешь задачи Claude Code, открой терминал (программу, где команды печатаются текстом, а не нажимаются мышкой) и вставь строку:

npx ruflo@latest init wizard

Что увидишь. Мастер настройки задаёт несколько вопросов о проекте и сам подбирает под них все нужные настройки, ничего не нужно донастраивать руками

Что это даёт. В папке проекта появляются файлы настроек RuFlo - агенты готовы к подключению

Подключи RuFlo к Claude Code

Куда нажать. В том же окне вставь ещё одну строку:

claude mcp add ruflo -- npx ruflo@latest mcp start

Что увидишь. Сообщение, что связка с Claude Code по имени ruflo добавлена

Что это даёт. Claude Code теперь видит RuFlo как один из своих инструментов и может сам вызывать агентов, когда задача этого требует

Дай Claude Code обычную задачу

Куда нажать. Пиши задачу как обычно: «собери фичу X», «прогони тесты», «проверь код на уязвимости» - без специальных команд для RuFlo

Что увидишь. Claude Code сам решает, когда позвать команду агентов вместо того, чтобы делать всё в одиночку - это видно по тому, что разные части задачи выполняются параллельно

Что это даёт. Одна задача, которая раньше шла по очереди, теперь разбирается сразу с нескольких сторон

Собери первую команду агентов вручную (по желанию)

Куда нажать. Если хочешь запустить команду агентов отдельной командой, а не ждать, пока Claude Code решит сам:

npx ruflo@latest swarm init --topology hierarchical --max-agents 8

Что увидишь. Инструмент поднимает восемь агентов в иерархии «королева и подчинённые» и готов принимать задачу

Что это даёт. Контроль над размером команды под конкретную задачу, а не только автоматический режим из Шага 3

Если что-то не подключилось

Три вещи, которые проверить по порядку:

  1. Строка claude mcp add выдала ошибку - убедись, что сам Claude Code вообще запускается из этого же окна командой claude, если нет, переустанови его сначала
  2. Связка с именем ruflo добавлена, но агенты не отвечают - начни с Claude Code новый диалог: старый ещё не знает про добавление
  3. Строка из Шага 1 выдаёт «not found» - значит программа, о которой шла речь в Шаге 0, на компьютере всё же не стоит отдельно от Claude Code, поставь её с nodejs.org, там же кнопка для твоей системы

Инструмент сейчас бесплатный

Открытый код, лицензия MIT, ставится и запускается уже сегодня без оплаты и подписки. Платишь только по своей обычной подписке Claude - и именно на ней RuFlo помогает сэкономить

Команда агентов - это только начало

Я одна, в декрете, без команды разработки строю системы на нейросетях сама. Один такой инструмент экономит расход в одной задаче, но собрать из связки агентов, промптов и своих готовых цепочек команд рабочую систему под конкретный проект - это уже не одна строка настройки

1.5 млн ₽ оборота проектов за год, с нуля и из декрета

RuFlo закрывает вопрос одной команды агентов на одной задаче. Если строишь целую систему - контент-завод, автоматизацию, продукт на нейросетях - одного инструмента мало, нужна архитектура под твою конкретную задачу
